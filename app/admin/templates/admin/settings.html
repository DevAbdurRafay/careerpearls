Platform Settings

Configure OAuth, email, and platform settings via the .env file. This page will host runtime settings in a future release.

  • Google OAuth: set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET
  • GitHub OAuth: set GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET
  • Email: set MAIL_USERNAME and MAIL_PASSWORD
  • Database: set DATABASE_URL for PostgreSQL in production
